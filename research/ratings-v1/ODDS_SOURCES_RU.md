# Бесплатные источники исторических коэффициентов — предварительный обзор (массовый бэкфилл не запускался)

**Важное ограничение проверки.** В этой облачной сессии прямой доступ к `www.football-data.co.uk` и `soccerdata.readthedocs.io` закрыт сетевой политикой (прокси отвечает 403 на CONNECT, WebFetch — «host not allowed»); обходить это я не стал. Поэтому ни один файл с коэффициентами **не скачан и не просмотрен**. Сведения ниже — результат веб-поиска (ссылки внизу) и моих знаний; пометка «не проверено» означает, что подтвердить по первичному источнику не удалось. Чтобы проверить качество на деле, нужно разрешить хосты (список в конце) или прислать по одному файлу.

|---|---|---|---|---|
| **football-data.co.uk** (CSV по сезонам и лигам) | Результаты и коэффициенты нескольких букмекеров (Bet365, Pinnacle, William Hill, др.), максимум и среднее по рынку; в поздних сезонах — закрывающие коэффициенты | Основные лиги Европы с 1993/94 (по поиску: «20+ европейских лиг с 1993 года»); текущий сезон обновляется еженедельно; «внеевропейские» лиги (Бразилия, США, Мексика, Япония и др.) — отдельные файлы, по моим сведениям с ~2012 и с меньшим набором букмекеров (**не проверено**) | Единый формат, есть счёт и дата (в поздних сезонах — и время начала); покрывает все наши лиги (PL, ELC, PD, SA, BL1, FL1, DED, PPL; BSA и MLS — через файлы «extra») | Набор букмекеров и столбцы меняются по сезонам (сайт сам предупреждает); момент снятия «закрытия» не документирован посекундно; названия команд отличаются от наших провайдеров (нужна таблица соответствий); лицензия — свободное использование без явных условий перераспределения (**уточнить**) |

## Что я рекомендую проверить первым (минимум запросов)
1. Разрешить хосты `www.football-data.co.uk` (и при желании `clubelo.com`, `api.clubelo.com`) в сетевых настройках сессии, **или** прислать по одному файлу: `E0` (АПЛ) сезона 2025/26 и файл «extra» для Бразилии/США.
2. На этих двух файлах оценить без массовой загрузки: покрытие матчей нашей базой (доля сопоставимых по дате и командам), состав и заполненность столбцов коэффициентов, перерасчёт «без маржи» (суммарная маржа в разумных пределах 1.02–1.08), наличие закрывающих коэффициентов и их отличие от открывающих, число несопоставленных названий команд.
3. Сверить с **нашими собственными сохранёнными рыночными котировками** (в экспорте есть 427 матчей 2026/27): совпадение по Pinnacle/Bet365 — прямая проверка качества без нового трафика.
4. Только после согласия — загрузка сезонов выбранных лиг, одним проходом, в отдельную папку исследований, с кэшем и контролем размера.

## Ограничения для использования в проверке модели
- Нужны **закрывающие** коэффициенты (или максимально близкие к старту); открывающие занижают точность «рынка».
- Для сопоставления с живыми сигналами необходим тот же букмекерский эталон (наименьшая маржа/Pinnacle), иначе сравнение смещено.
- Исторические файлы не содержат информации о составах; то есть они проверяют модель результатов, не дают «новой информации» сами по себе.
