# FVM v0.4 - Windows-версия

FVM - Telegram-бот для просмотра футбольных матчей на ближайшие 24 часа, предварительной модели 1X2 и поиска возможного value при наличии коэффициентов.

## Что нужно для запуска

- Windows.
- Node.js 18 или новее.
- Telegram Bot Token.
- `chat_id` пользователя или группы, которой разрешен доступ.
- Ключ football-data.org.
- Ключ The Odds API, если нужны реальные коэффициенты и проверка value.

## Первый запуск

1. Запустите `start.bat`.
2. Если файла `.env` еще нет, скрипт создаст его из `.env.example` и откроет в Блокноте.
3. Заполните обязательные поля:
   - `TELEGRAM_BOT_TOKEN`
   - `ALLOWED_CHAT_IDS`
   - `FOOTBALL_DATA_TOKEN`
4. Сохраните `.env`.
5. Закройте Блокнот.
6. Запустите `start.bat` еще раз.

Важно: `ALLOWED_CHAT_IDS` теперь обязателен. Если оставить его пустым, бот не запустится. Это защищает бота от случайного доступа посторонних пользователей.

## Пример `.env`

```env
TELEGRAM_BOT_TOKEN=...
ALLOWED_CHAT_IDS=123456789
FOOTBALL_DATA_TOKEN=...
THE_ODDS_API_KEY=
ODDS_REGION=eu
MIN_EDGE_PERCENT=4
MIN_DATA_QUALITY=65
REFRESH_MINUTES=30
REQUEST_TIMEOUT_SECONDS=20
LOG_DENIED_ACCESS=true
```

## Команды в Telegram

- `/start` - открыть dashboard.
- `/dashboard` - показать текущую сводку.
- `/refresh` - принудительно обновить данные.
- `/status` - показать состояние ключей, кеша, таймаута и ошибок источников.
- `/id` - показать текущий `chat_id`.

## Что исправлено и усилено

- Русские тексты восстановлены в нормальной кодировке.
- `start.bat` проверяет наличие Node.js, npm и версию Node.js.
- `start.bat` проверяет наличие `.env.example` перед созданием `.env`.
- Бот не запускается с пустым `ALLOWED_CHAT_IDS`.
- Внешние HTTP-запросы получили таймаут через `REQUEST_TIMEOUT_SECONDS`.
- Добавлена команда `/status`.

## Ограничения модели

Текущая модель предварительная. Она использует:

- таблицу;
- очки за матч;
- разницу мячей;
- последние матчи;
- домашнее преимущество;
- реальную линию 1X2 при наличии Odds API.

Полные xG, составы, травмы, SCI, MAI, DNB, AH, OU и BTTS не подключены.
